# Lovable WorkHub

Buat aplikasi workhub personal berbahasa Indonesia dengan backend Supabase eksternal. Fitur: task harian, pencatatan pekerjaan, pekerjaan mendatang, notulen, dan file storage yang tersimpan di Supabase. Buat autentikasi login dengan role admin dan viewer, rute/data terlindungi sesuai role; admin dapat membuat akun user lain dan mengatur perannya. Siapkan akun admin pertama satria62317@gmail.com dengan password default yang aman dan instruksi jelas untuk menggantinya, serta jadikan otomatis admin setelah akun dibuat. Jelaskan kebutuhan pengguna untuk menghubungkan Supabase mereka di Project Settings > Integrations > Supabase sebelum backend dapat dipakai.
